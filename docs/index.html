Built for Real Agentic Work

Designed with intentional craft, strict platform boundaries, and zero extraneous dependencies.

Zero-Key Free Chat

Start chatting immediately on first launch with tested, zero-key anonymous free models (OpenCode Zen, Pollinations). No credit card, no sign-ups, and no API key required.

Device Auth & Subscriptions

First-class device sign-in for GitHub Copilot (individual and enterprise), OpenAI Codex, and ChatGPT web sessions. Full multi-turn conversation, streaming, and tool calls supported natively.

Curated Model Shortlist

Never scroll through 1,000s of raw endpoints. Curate your active chat shortlist with 1-click model buttons directly from any connected provider.

Embeddable Kernel

The runtime engine serves as an in-process embeddable kernel for downstream consumers like Facet and Midden, without spawning foreign subprocesses.

Bounded Capability Modules

Extensible via isolated, detached capability modules with built-in human-in-the-loop approval gates for chargeable or destructive operations.

Zero External Dependencies

Single-bundle native binary with embedded SQLite, offline vector brand marks, and statically compiled web cockpit. No Python, Node, or Docker needed.

How It Works

01 / SETUP

Run the One-Liner

Paste the installer command into your shell. It verifies your environment and sets your dashboard password directly in the terminal.

02 / PROBE

Live Pre-Flight Test

The installer pings free zero-key model endpoints in 2 seconds, confirms reachability, and auto-wires a verified working model.

03 / LAUNCH

Start Chatting

Facet Studio launches in your browser on http://localhost:18800 (or clean port 19900) ready to chat on turn 1.

In-Process Go Embedding & Headless CLI

Downstream applications like Facet and Midden embed the runtime directly in Go memory with zero CLI shell-outs. Terminal operators can manage models and run turns entirely headlessly.

Standalone Kernel CLI 
# Fresh setup with auto-wired free models
facet-studio-kernel onboard

# Inspect all 50+ curated providers
facet-studio-kernel model roster

# Probe endpoint latency and health
facet-studio-kernel model ping opencode-zen

# Connect working free models without a browser
facet-studio-kernel model auto-free

# Run an agent turn directly in terminal
facet-studio-kernel agent "Explain this repository"
In-Process Go Embedding 
import (
    "github.com/xibodev/facet-studio/pkg/agent"
    "github.com/xibodev/facet-studio/pkg/config"
)

// 1. Load config (or pre-seeded defaults)
cfg, _ := config.LoadConfig(path)

// 2. Initialize agent in memory
loop, _ := agent.NewAgentLoop(cfg, domainTools)

// 3. Stream turns with Go callbacks
loop.ProcessTurn(ctx, sessionID, prompt, func(chunk string) {
    ui.RenderStream(chunk)
})
