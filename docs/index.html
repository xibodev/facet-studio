THE ARCHITECTURE

One brain. Multiple surfaces. Zero fragile shell-outs.

The kernel owns conversation, models, credentials, and tool execution. Presentation surfaces merely project that state.

  1. 01 Kernel Engine Turn loop, memory cairns, tool calling, and fallback resilience
  2. 02 Service Layer Curated registry, reachability ping, catalog sync, free auto-connect
  3. 03 Headed Shell Headed web cockpit, desktop launcher, and lifecycle supervisor
  4. 04 Host Applications Midden & Facet native in-process Go embedding

Downstream applications bind domain tools natively in Go memory without foreign subprocesses, socket serialization, or stdin/stdout text scraping.

MODEL SELECTION

IN-PROCESS RUNTIME
Embeddable Kernel
The runtime engine serves as an in-process embeddable kernel for downstream consumers like Facet and Midden, without spawning foreign subprocesses.
EXTENSIBILITY
Bounded Capability Modules
Extensible via isolated, detached capability modules with built-in human-in-the-loop approval gates for chargeable or destructive operations.
PACKAGING
Zero External Dependencies
Single-bundle native binary with embedded SQLite, offline vector brand marks, and statically compiled web cockpit. No Python, Node, or Docker required.

IN-PROCESS GO EMBEDDING
import (
    "github.com/xibodev/facet-studio/pkg/agent"
    "github.com/xibodev/facet-studio/pkg/config"
)

// 1. Load config (or pre-seeded defaults)
cfg, _ := config.LoadConfig(path)

// 2. Initialize agent in memory
loop, _ := agent.NewAgentLoop(cfg, domainTools)

// 3. Stream turns with Go callbacks
loop.ProcessTurn(ctx, sessionID, prompt, func(chunk string) {
    ui.RenderStream(chunk)
})
