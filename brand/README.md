# Facet Studio Brand Assets

This directory is the editable public brand kit for Facet Studio. Read [BRAND.md](BRAND.md) for naming, color, and positioning rules.

## Asset index

| Asset | Purpose |
|---|---|
| `logos/mark.svg` | Primary facet mark on Studio Navy squircle tile |
| `logos/mark-inverse.svg` | Transparent facet crystal mark for custom surfaces |
| `logos/lockup.svg` | Horizontal facet crystal + `facet.studio` wordmark |
| `logos/lockup-inverse.svg` | Horizontal lockup for dark surfaces |
| `logos/wordmark.svg` | `facet.studio` compact wordmark for light surfaces |
| `logos/wordmark-inverse.svg` | `facet.studio` compact wordmark for dark surfaces |
| `logos/mono-black.svg` | Single-color black facet mark |
| `logos/mono-white.svg` | Single-color white facet mark |
| `icons/favicon.svg` | 32x32 browser favicon |
| `icons/app-icon.svg` | 512x512 app icon master |
| `icons/icon-192.svg` | 192x192 PWA app icon |
| `icons/icon-512.svg` | 512x512 PWA app icon |
| `og/og-default.svg` | 1200x630 social preview SVG master |
| `tokens.json` | Design tokens in tool-neutral JSON |
| `tokens.css` | CSS custom property projection |
| `preview.html` | Browser preview of all brand assets |

## Consumers

- Documentation website (`docs/`) consumes `brand/` assets directly.
- Package listings, releases, and social media consume `brand/icons/` and `brand/og/`.
